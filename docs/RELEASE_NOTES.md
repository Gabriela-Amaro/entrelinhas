### Escolha seu instalador

- **Ubuntu, Debian e derivados:** baixe o `.deb` e abra no instalador de aplicativos, ou use `sudo apt install ./Entrelinhas-*-linux-amd64.deb`.
- **Fedora e derivados:** baixe o `.rpm` e abra no instalador de aplicativos, ou use `sudo dnf install ./Entrelinhas-*-linux-x86_64.rpm`.
- **Outros Linux x64 / sem acesso de administrador:** baixe `Entrelinhas-*-linux-x64.tar.gz`, extraia e execute `sh install.sh` na pasta extraída. Instala o app no menu sem Node.js, npm ou FUSE.
- **Windows x64:** execute `Entrelinhas-*-windows-x64-setup.exe`. O instalador cria a entrada no menu Iniciar.
- **macOS Intel / Apple Silicon:** baixe o `.dmg` de sua arquitetura e arraste Entrelinhas para Aplicativos. Depois procure por Entrelinhas no Spotlight.
- **AppImage:** disponível para uso portátil; o arquivo sozinho não registra uma entrada no menu. Para integração automática, use um dos instaladores Linux acima.

Os pacotes Windows e macOS não possuem certificado de assinatura/notarização nesta versão. A abertura pode depender das políticas de segurança do sistema.

`SHA256SUMS.txt` contém os hashes dos instaladores. Seus arquivos originais e a sessão ficam no seu computador. Rascunhos só são gravados nos arquivos originais ao usar Salvar / Ctrl+S.
